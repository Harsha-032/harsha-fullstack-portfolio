# Harsha Full-Stack Portfolio Docs

This folder documents the project as a production-style learning application, not just a portfolio website.

The project is intentionally used to learn real full-stack engineering:

- modular backend architecture
- REST API design
- OpenAPI schema generation
- Swagger API documentation
- frontend state and API integration
- validation and testing
- deployment-ready thinking
